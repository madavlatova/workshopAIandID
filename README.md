# Практикум «Алхимия обучения»

Страница практикума мастер-класса «Алхимия обучения: сочетание классического педдизайна и нейросетей» (Институт образования НИУ ВШЭ).

Участники проектируют фрагмент курса «Атрибуция предметов художественной керамики при подготовке выставки» по модели 4C/ID с помощью нейросети: 7 шагов-промптов, самопроверка, справка, литература, отчет команды.

Разработчик страницы: Давлатова Мадина Асатуллоевна.
